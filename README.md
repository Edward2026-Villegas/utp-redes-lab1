🔬 Laboratorio 1: Fundamentos de Redes
Laboratorio desarrollado en la asignatura Sistemas Colaborativos (UTP, 2026).
🎯 Propósito
Comprender el flujo básico de comunicación en una red local y documentar el proceso de forma reproducible.
🗺️ Topología
Equipo	Interfaz	Dirección IP	Máscara
Router R1	Gi0/0	192.168.1.1	255.255.255.0
Switch SW1	VLAN 1	192.168.1.2	255.255.255.0
PC1	NIC	192.168.1.10	255.255.255.0
PC2	NIC	192.168.1.11	255.255.255.0
> Reemplaza esta tabla con tu topología real e inserta una captura: `![Topología](topologia.png)`
⚙️ Procedimiento
Armar la topología en Cisco Packet Tracer.
Asignar direcciones IP a cada equipo.
Verificar conectividad con `ping`.
Capturar tráfico ICMP con Wireshark y analizar los paquetes.
Documentar resultados y capturas.
🧰 Herramientas
Cisco Packet Tracer, Wireshark, Git/GitHub
